# Machine Learning for Surrogate Variables in Lattice Quantum Chromodynamics:

Using Machine Learning to map relations between Quark propogations to generate Surrogate Variables generated by Lattice Quantum Chromodynamics as a way to reduce computation cost with machine learning models.

ML models used: 
- Gradient Boosted Regressor Trees
- Multi Layer Perceptron
- 1D Convolutional Neural Networks
- Encoder Transformers

See papers in docs/ for further details regarding project
Please note the paper "MachineLearningForLatticeQCD.pdf" is my own written paper however, due to limitations provided by the template used (MRNAS) I do not have control over the size or placement of the images. Will export to APS format soon.
